Maximalist

As much as the paper will honestly take. Just under nine point, a measure of about ninety-six characters, a 0.4 inch margin and section gaps measured in single digits. The builder already flags it print-safe, which tells you what it is for.

The numbers

Every figure below is a value in the template registry the builder ships (assets/js/render/templates.js), or a size derived from it by the same multipliers the document stylesheet uses. Body text is not the preset’s nominal point size: it is that figure corrected for the face’s optical size, which is why a 10 pt Helvetica preset renders at 11.73 pt here. Nothing on this page is a measured pass rate or a hiring outcome, because neither exists.

What it is for

Good at

  • Forty years of service and a decision to show all of it. This is the only preset that fits that on one sheet without lying about the dates.
  • Public sector and academic applications with a service-history convention that expects a full list.
  • Print on a decent laser, which is the route this preset is tuned for.
  • A reader who has been given the full document and has time.

Bad at

  • Comfortable reading. This is the smallest type in the set on the widest measure, and that is the hardest combination to read.
  • Anything visual. There is no room for a rule, a tint or a mark of any kind.
  • A modern screen at a comfortable zoom, where the page reads as an apology.
  • A short career. Two entries on a page built for twenty looks like you are hiding something.

ATS profile

Clean

One column, no tables, no images, no graphics, no colour. It is the least decorated page in the set and therefore among the easiest to read mechanically.

The density is a reading decision, not a parsing one. A parser reading nine point Tahoe reads the same text stream as a parser reading eleven point Arial.

The honest caveat: a page this dense is a page someone is more likely to skip, and skipping is what a parsed application is usually a response to.

Still yours to get right

A clean layout with a placeholder employer named “Company 1” is still a document a parser discards. No template can fix a sentence that describes effort instead of effect. Start with the resume basics guide and the one on quantifying impact.
