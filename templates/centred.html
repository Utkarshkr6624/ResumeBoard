Centred

Name, headline and contact all centred, over a rule under every section heading. Formal, symmetrical, and the one preset in the set where the header is the design.

The numbers

Every figure below is a value in the template registry the builder ships (assets/js/render/templates.js), or a size derived from it by the same multipliers the document stylesheet uses. Body text is not the preset’s nominal point size: it is that figure corrected for the face’s optical size, which is why a 10 pt Helvetica preset renders at 11.73 pt here. Nothing on this page is a measured pass rate or a hiring outcome, because neither exists.

What it is for

Good at

  • Roles with a formal application process, where a symmetrical page reads as an official document.
  • Education and public sector, where centred letterheads are the convention rather than a choice.
  • A short document, since the header takes up a third of the first screen.
  • Print, where a centred page is the shape a reader expects from a formal letter.

Bad at

  • Scanning. Centred text has a ragged left edge, and a ragged left edge is exactly what a six-second skim uses to find where to look.
  • A long contact run, because a centred row of facts that wraps is worse than a left-aligned one that wraps.
  • Anything modern. This is a letterhead, and reading it as a resume is a category error.
  • Print with an even duplex copier, where the centring is the first thing to drift.

ATS profile

Clean

One column, no tables, no images, and a heading alone on its line. Centring is a text-align value and changes nothing about the order the DOM describes.

A text extractor is indifferent to alignment. It reads name, headline, contact, then the sections, in the order they appear in the document.

The honest criticism of this one is not a parsing one. It is that a ragged left edge is a real cost to a reader scanning a stack of pages.

Still yours to get right

A clean layout with a placeholder employer named “Company 1” is still a document a parser discards. No template can fix a sentence that describes effort instead of effect. Start with the resume basics guide and the one on quantifying impact.
