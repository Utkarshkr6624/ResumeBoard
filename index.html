Questions people actually ask

Can it really read my LinkedIn?

It reads your data export, not your profile page. LinkedIn's export is a file they email you after you request it from Settings, and we parse it in your browser. A profile page itself cannot be read by any website without being signed in, which is a deliberate choice on LinkedIn's part — so we do not pretend otherwise, and the export path is better anyway because it has every date and every entry.

How do I get the LinkedIn export?

LinkedIn → Settings & privacy → Data privacy → Get a copy of your data. Tick Include profile data, request the archive, and they email a download link. It arrives as a ZIP. Open the editor, choose LinkedIn export, and drop the file in.

Will it get past the filters?

Nobody can promise that, including us. What we can do is tell you the failure modes that are actually documented — contact details sitting in a header, two-column layouts that scramble reading order, icon glyphs used as bullets, ambiguous dates, fonts a parser will not recognise — and show you the exact line that caused each one. The templates that are safest are marked as safest.

Is it really free?

Yes, and not as a trial. PDF, Word, Markdown, plain text and JSON export have no watermark, no page limit and no account. There is no pro tier. That is a deliberate position: the export is the thing you already made, so charging for it would be charging you for your own work.

Where is my data?

In your browser, in IndexedDB, and nowhere else. There is no server to send it to. If you clear browsing data you will lose it, so export a JSON backup before you do, or use a share link, which encodes the whole resume into the URL itself.

Can I move it to another computer?

Export to JSON and import it there. It contains everything, it is plain text you can read and diff, and it round-trips losslessly. That is also the answer to being locked into any tool.
